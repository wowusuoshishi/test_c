# 源代码解释：从训练入口到视频

## 1. 代码目录

```text
Code/
  SAC_train.py              # 上游原始训练脚本（固定路径，便于对照）
  SAC_test.py               # 上游测试脚本
  SAC_test_record.py        # 上游录制脚本
  visualize.py              # 上游奖励曲线脚本
reproduction/
  SAC_train_reproduce.py    # 可配置、可追溯的正式训练入口
  evaluate_checkpoint.py    # 单个 checkpoint 的确定性评估和视频
  best_model_monitor.py     # 逐 checkpoint 评估并自动保留 best_model
  summarize_evaluations.py  # 把 JSON 聚合成 CSV/Markdown
  plot_reproduction_results.py # 由真实 CSV 绘图
```

## 2. `reproduction/SAC_train_reproduce.py`

### 环境和观测

`make_env()` 创建 `gym.make("HumanoidStandup-v5")`，随后用 `TruncatedObservationWrapper` 截取 `observation[:45]`。这不是改变 MuJoCo 的物理环境，而是改变送进神经网络的观测向量。

### 网络初始化

`custom_init()` 对每个线性层使用 Xavier uniform 初始化、bias 置零。训练正式开始前执行 `model.policy.apply(custom_init)`，所以保存的 checkpoint 已包含这个初始化后的网络。

### SAC 模型

```python
model = SAC(
    "MlpPolicy", env,
    learning_rate=3e-4, buffer_size=1_000_000,
    learning_starts=10_000, batch_size=256,
    train_freq=1, gamma=0.99, tau=0.005,
    ent_coef="auto", gradient_steps=1,
    target_update_interval=1, target_entropy=-17,
    device="cuda", seed=42,
)
```

这段由 Stable-Baselines3 执行 actor、双 critic、replay buffer、自动熵系数和 target network 的具体更新；每个参数的含义见 [`SAC参数与复现说明.md`](SAC参数与复现说明.md)。

### 回调和可追溯输出

- `CheckpointCallback` 定期保存模型和 replay buffer；
- `RewardLoggerCallback` 将每个完整 episode 的未修改环境奖励写入 CSV；
- `manifest.json`/`formal_training_manifest.json` 写入版本、GPU、seed、步数和超参数；
- `finally: env.close()` 确保异常或正常结束时关闭 MuJoCo 环境。

## 3. `reproduction/evaluate_checkpoint.py`

1. `SAC.load()` 加载一个 checkpoint，不继续训练；
2. `model.predict(..., deterministic=True)` 关闭策略采样噪声，保证不同检查点可比较；
3. 从 `env.unwrapped.data.qpos[2]` 读取躯干高度；
4. 统计 return、最高高度、最后 100 步平均高度、最后 200 步超过 1.2 m 的比例；
5. 用 `cv2.VideoWriter` 把 RGB 帧写成 MP4。

因此视频是评估产物，不是训练期间的实时录像。

## 4. `reproduction/best_model_monitor.py`

监控器与训练进程分离：它只读取已经生成的 checkpoint，不修改训练模型或 replay buffer。`score()` 按 `(stable_episode_count, mean_last_100_height_m, mean_return)` 排序，当新检查点更好时原子复制为 `best_model.zip` 并写 `best_model_manifest.json`。

## 5. `summarize_evaluations.py` 与绘图

`summarize_evaluations.py` 读取 `Results/checkpoint_evaluations_raw/*_steps.json`，生成：

- `Results/checkpoint_metrics.csv`：每个检查点一行；
- `EXPERIMENT_REPORT.md`：最佳模型、前十名、限制和产物链接。

`plot_reproduction_results.py` 只读取 CSV，不重新计算奖励，生成 [`../Results/reproduction_training_summary.png`](../Results/reproduction_training_summary.png)。

## 6. CleanRL 参考代码如何对应

CleanRL 的 `cleanrl/sac_continuous_action.py` 把 SAC 更新写在一个文件中：

```text
Actor.sample()                  -> tanh 高斯策略、动作缩放、log_prob 修正
SoftQNetwork.forward()         -> Q(s,a)
target_min_q - alpha*log_pi    -> critic bootstrap target
(alpha*log_pi - min_q).mean()  -> actor loss
Polyak update(tau)             -> target critic 更新
```

本项目没有声称重新实现一份独立 CleanRL 文件；正式模型使用上游 SB3 代码路径，但数学逻辑相同。这样既保留了原始仓库的可复现实验，又能用 CleanRL 代码逐行讲解 SAC 更新。

## 7. 建议的讲解顺序

先讲 `state → actor → action → MuJoCo → reward` 的闭环，再讲 replay buffer 和两个 critic，最后用 `best_model_monitor.py` 解释为什么不能只看最高奖励。这样比直接展示 7,198 行训练日志更容易让初学者理解。
