# 参考资料与本项目对应关系

1. Haarnoja et al., *Soft Actor-Critic Algorithms and Applications*, arXiv:1801.01290。用于最大熵目标、随机 actor、自动温度和 off-policy actor-critic 的理论依据：<https://arxiv.org/abs/1801.01290>
2. Gymnasium 官方 `HumanoidStandup-v5` 文档。用于动作/观测空间、奖励、reset 和 MuJoCo 任务定义：<https://gymnasium.farama.org/environments/mujoco/humanoid_standup/>
3. CleanRL `sac_continuous_action.py`。用于单文件 SAC 更新流程、twin Q、reparameterized actor、自动 entropy 和 Polyak 更新对照：<https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/sac_continuous_action.py>
4. Stable-Baselines3 SAC 文档。正式训练脚本通过 SB3 执行 SAC 网络和优化器更新：<https://stable-baselines3.readthedocs.io/en/master/modules/sac.html>
5. 本项目上游仓库与固定提交：`bcrockett21/SACMujoco_HumanoidStandup-v5`，commit `84f8a6443af0c8f476b0e591869473da44d2583a`。正式实验的路径、wrapper 和超参数以该提交的可执行 `Code/SAC_train.py` 为准。

## 阅读提示

- 论文解释“为什么最大熵 SAC 有效”；
- Gymnasium 文档解释“机器人和动作空间是什么”；
- CleanRL 代码解释“每一步 SAC 更新怎样写成程序”；
- 本仓库的 `reproduction/` 目录解释“如何在服务器上可追溯地训练、评估和选 best model”。
